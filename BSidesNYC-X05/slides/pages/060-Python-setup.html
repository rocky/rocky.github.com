Python Installation via OS/distro Package Installer

Install using an OS package manager.

On GNU/Linux systems via snap 

	$ python -m venv
$ sudo snap install python3-alt-3.13

Ubuntu —

	$ sudo apt install python3 # or python3.12 etc.

MacOS —

	$ brew install python3@3.13

MS Windows —

	choco install python --version=3.12 --params '"/InstallDir:C:\Python313"'

Today, we are going to look at Python bytecode. A number of the tools we will be using are written in Python. The exact version of Python and the Python implementation are not that important; but it will help if you have some version of Python installed. Python Installation via a Virtual Environment

Install in a virtual environment.

virtualenv —

	$ cd BSides-2025-Workshop
	  $ python -m venv
	  $ venv/bin/activate venv

pyenv —

	$ curl https://pyenv.run | bash
	  $ pyenv install 3.13
	  $ # Follow instructions at: https://github.com/pyenv/pyenv#b-set-up-your-shell-environment-for-pyenv

pyenv-win —

	Invoke-WebRequest -UseBasicParsing -Uri "https://raw.githubusercontent.com/pyenv-win/pyenv-win/master/pyenv-win/install-pyenv-win.ps1" -OutFile "./install-pyenv-win.ps1"; &"./install-pyenv-win.ps1"
pyenv install 3.1.3

Often, what you want to do is have an isolated Python environment for the project you are working on. For this, use virtualenv which typically comes with Python nowadays.

[DOWN to pyenv] 6.4 ⟶ 6.4

Another method for setting a Python environment is by using pyenv. I use this. It allows me to switch between many different versions of Python. I do this because, in working with bytecode, I often need to switch between different versions of Python. virtualenv will also accommodate this, but for my work, I would need many different virtual environments spanning many inter-connected devoloppment environments.

pyenv-win is the corresponding MS Windows version of pyenv

You will find the above commands listed and copyable in section 6.4 of the workshop guide.

Optional Programs

These programs may be useful, but are optional:

  • xxd — hex display and conversion from hex to binary
  • pycdc and pycdas — Alternate decompiler/disassembler for many Python versions. It is written in C++.
  • pylingual — Decompiler for Python 3.6 to 3.11. To run locally, use need PyTorch and CUDA installed.

The following are optional programs to have around. Strictly speaking, you do not need these, but they might be useful as alternatives to some of the ways we show. Section 6.6 of the Workshop README has some links that might be useful.
