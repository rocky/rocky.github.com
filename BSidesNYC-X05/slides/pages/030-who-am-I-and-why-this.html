Why Study Python Bytecode?

High-level bytecode is attractive for malware writers because:

  • Portable.
  • Compact — low footprint.
  • Impervious to general-purpose binary analysis tools

compact,

and impervious to standard general-purpose analysis tools. A while back, a couple of people from Microsoft contacted me regarding a malware bot-net that was active on Microsoft Windows. The malware was written in Python 2.7. As I mentioned before, the standard analysis tools like Hex Rays or Ghidra were of no use to them.

Then in April of 2023, malware started appearing in bytecode on Python's package server PyPI. Again, automated security checks did not detect this. The code is neither machine code nor Python source code.

Languages that use high-level byecode are not decreasing. The Python language and bytecode continue to change. Python’s generated bytecode has become more complex and harder to decompile.
