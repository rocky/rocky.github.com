trepan3k — a debugger that can debug without source (and decompile)

Currently I haven't added bytecode support x-python beyond 3.12 bytecode. And even here, 3.11 and 3.12 bytecode interpretation is not complete.

But for later Python, a Python debugger I've written does support debugging using just the bytecode file when there is no source code around. This debugger, trepan3k, is the only debugger I know of that can do this. If you have a Python debugger other than the ones I wrote, I invite you to try that debugger on this bytecode to see what you get.

trepan3k vs trepan-xpy

  • pro: trepan3k uses a full Python interpreter so it supports Pythons bytecode more accurately and fully
  • con: trepan3k only runs one version of bytecode—the version of the Python interpreter corresponding to the Python installation
  • pro: trepan3k supports some decompilers
  • con: Not enough decompilers, and more work could be made to do this better
  • con: trepan3k can't show evaluation stack or block stack (when it exists)
  • con: Like decompiler support, disassembly support could be better

    • Here are some pro's and cons. trepanx is somewhat of a toy since it is an interpreter and it is incomplete, and I might have implemented things wrong. But trepan3k is guarenteed to preserve semantics.
